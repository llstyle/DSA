# Программа управления событиями

Программа для управления списком событий с возможностью добавления, редактирования, поиска, сортировки и сохранения данных в файлы.

## 🛠 Подготовка

Для работы вам понадобится компилятор **GCC**. Проверьте его наличие в терминале:

```bash
gcc --version
```

---

## 🚀 Как запустить

### 1. Компиляция

Соберите программу из нескольких модулей:

```bash
gcc -o events main.c data.c -Wall
```

### 2. Запуск

Выполните созданный файл:

- **Для Linux и macOS:**

```bash
./events
```

- **Для Windows:**

```bash
events.exe
```

## 📋 Возможности программы

1. **Добавить событие** — добавление нового события с валидацией даты
2. **Вывести все** — показать все сохраненные события
3. **Редактировать** — изменить название, дату, место или количество участников
4. **Поиск** — найти события по названию
5. **Удалить последний** — удалить последнее событие из списка
6. **Сортировать** — сортировка по названию, дате, месту или участникам
7. **Вставить на позицию** — добавить событие в указанную позицию
8. **Удалить по индексу** — удалить конкретное событие
9. **Очистить список** — удалить все события
10. **Сохранить в файл** — ручное сохранение данных
11. **Загрузить из файла** — ручная загрузка данных
12. **Выход** — выход с автоматическим сохранением

---

## 💾 Работа с файлами

- **Автосохранение:** При выходе (пункт 0) данные автоматически сохраняются
- **Ручное управление:** Доступны пункты меню для сохранения и загрузки
- **Формат файла:** Бинарный формат для надежного хранения структур

## 💡 Полезные флаги

Если при компиляции возникают ошибки или нужны дополнительные настройки:

- `-Wall` — показать все предупреждения (рекомендуется)
- `-g` — включить отладочную информацию
- `-O2` — оптимизация кода

Пример:

```bash
gcc -Wall -g -o events main.c data.c
```
