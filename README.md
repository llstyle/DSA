````markdown
# Инструкция по запуску (main.c)

Этот файл содержит краткое руководство по компиляции и запуску программы, написанной на языке C.

---

## 🛠 Подготовка

Для работы вам понадобится компилятор **GCC**. Проверьте его наличие в терминале:

```bash
gcc --version
```
````

## 🚀 Как запустить

### 1. Компиляция

Соберите исходный код в исполняемый файл с помощью следующей команды:

```bash
gcc main.c -o app

```

_Здесь `app` — это имя программы, которое получится на выходе._

### 2. Запуск

Выполните созданный файл:

- **Для Linux и macOS:**

```bash
./app

```

- **Для Windows:**

```bash
app.exe

```

---

## 💡 Полезные флаги

Если при компиляции возникают ошибки или нужны дополнительные настройки:

- `-Wall` — показать все предупреждения (рекомендуется).
- `-lm` — подключить математическую библиотеку (если используешь `<math.h>`).

Пример:

```bash
gcc -Wall main.c -o app -lm

```
